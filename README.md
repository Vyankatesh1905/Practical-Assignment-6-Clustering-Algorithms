# Practical-Assignment-6-Clustering-Algorithms

- This project implements four clustering algorithms: K-Means, Hierarchical Clustering, Gaussian Mixture Model (GMM), and DBSCAN.
- The Wine dataset is used to identify groups based on chemical features.
- Python and scikit-learn are used for implementation.

## How to Run
1. Install dependencies: `pip install scikit-learn pandas numpy matplotlib`
2. Run: `python clustering.py`
